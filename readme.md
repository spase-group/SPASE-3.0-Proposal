These advances have been carefully developed based on feedback from the community obtained both in the documents below and from feedback given based on the linked presentations below.

### [Report on SPASE 3.0 Effort](https://doi.org/10.5281/zenodo.17381463) - Oct 2025
SPASE 3.0 is the next generation of the SPASE metadata format for Heliophysics. Its development is driven by the need to increase support for FAIR principles and solve difficulties with creating and managing SPASE resources. A set of space and solar physics use cases for using SPASE model with the Heliophysics-wide search interface, as the SPASE model main function, were proposed and voted on by members of the international Heliophysics community. The use cases include both the original set of use cases and an additional set based on the fundamental functionality of the SPASE model current version not captured in the original use cases. The accepted use cases were used to extract functional requirements for the SPASE 3.0 model. We discuss the functional requirements, a draft SPASE 3.0 model design with resource description examples, and improvements over the SPASE model current version.

### [SPASE 3.0 Dataset Functional Requirements](https://doi.org/10.5281/zenodo.17553966) - Nov 2025
SPASE 3.0 Dataset resource type functional requirements based on the Heliophysics SPASE community accepted use cases (https://doi.org/10.5281/zenodo.17553643). The requirements drive the SPASE 3.0  data model development (https://doi.org/10.5281/zenodo.17381463).

### [SPASE 3.0 Use Cases Prioritization](https://doi.org/10.5281/zenodo.17553643) - Nov 2025
This document presents the 66 use cases accepted by community vote of the international Heliophysics SPASE community. The vote percentages are included with yellow highlighting. Prioritization of the use cases are indicated below the voting percentages for each use case with notes on each where relevant. These use cases fed into the development of the requirements table (https://doi.org/10.5281/zenodo.17553965), from which the structure of SPASE 3.0 was developed (https://doi.org/10.5281/zenodo.17381463).
